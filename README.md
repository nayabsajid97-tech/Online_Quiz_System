# 📱 Online Quiz System (Android Application)

## 📌 Project Overview
Online Quiz System ek **Android-based mobile application** hai jo students aur teachers ke liye design ki gayi hai.  
Is app ke zariye teachers quizzes create kar sakte hain aur students quizzes attempt karke apna result dekh sakte hain.

Ye project **Android Studio** mein develop kiya gaya hai aur real-world quiz system ke concepts par based hai.

---

## 🎯 Objectives
- Students ke liye online quizzes ka system provide karna
- Teachers ko quiz create aur manage karne ki facility dena
- Automatic result generation
- Secure login system

---

## 👥 User Roles
### 👨‍🏫 Teacher
- Login / Signup
- Quiz create karna
- Questions add karna
- Student results dekhna

### 👩‍🎓 Student
- Login / Signup
- Available quizzes dekhna
- Quiz attempt karna
- Result dekhna

---

## 🧩 Features
- User Authentication (Login / Signup)
- Quiz Creation & Attempt
- MCQs based questions
- Automatic score calculation
- Result display
- Simple & user-friendly UI

---

## 🛠 Technologies Used
- **Language:** Java
- **IDE:** Android Studio
- **Database:** SQLite / Firebase
- **UI Design:** XML
- **Data Storage:** Shared Preferences
- **Architecture:** Activities, Adapters, RecyclerView

---

## 🗄 Database Usage
- **SQLite:** Local data storage (quiz, questions, results)
- **Firebase:** User authentication & cloud-based data handling
- **Shared Preferences:** User login session maintain karne ke liye

---

## 📱 Screens / Modules
- Splash Screen
- Login Screen
- Signup Screen
- Teacher Dashboard
- Student Dashboard
- Quiz List Screen
- Quiz Attempt Screen
- Result Screen

---

## 🔐 Shared Preferences Usage
Shared Preferences ka use:
- User login session save karne ke liye
- Bar-bar login se bachne ke liye
- User role (Student / Teacher) store karne ke liye

---

## 🚀 How to Run Project
1. Android Studio open karo
2. Project import karo
3. Gradle sync hone do
4. Emulator ya real device connect karo
5. Run ▶️ button press karo
