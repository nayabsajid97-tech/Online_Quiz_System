Online Quiz System (Android Application)
Project Overview

Online Quiz System is an Android-based mobile application designed for students and teachers.
Through this application, teachers can create and manage quizzes, while students can attempt quizzes and view their results.

This project is developed in Android Studio and is based on real-world online quiz system concepts.

Objectives

To provide an online quiz system for students

To allow teachers to create and manage quizzes

To generate quiz results automatically

To implement a secure login system

User Roles
Teacher

Login / Signup

Create quizzes

Add questions

View student results

Student

Login / Signup

View available quizzes

Attempt quizzes

View results

Features

User authentication (Login / Signup)

Quiz creation and quiz attempt

MCQs-based questions

Automatic score calculation

Result display

Simple and user-friendly UI

Technologies Used

Language: Java

IDE: Android Studio

Database: SQLite / Firebase

UI Design: XML

Data Storage: Shared Preferences

Architecture: Activities, Adapters, RecyclerView

Database Usage

SQLite: Used for local data storage (quizzes, questions, results)

Firebase: Used for user authentication and cloud-based data handling

Shared Preferences: Used to maintain user login sessions

Shared Preferences Usage

Shared Preferences are used to:
